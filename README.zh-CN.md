# SVG 矢量编辑器 · SVG Editor

> 单个 HTML 文件里的轻量矢量编辑器：矩形、圆、直线、自由笔、文字，导出干净且**可继续编辑**的 SVG 源码。

## 能做什么

- **5 种绘制工具** —— 矩形、圆形、直线、自由笔、文字（另有插入图片，内嵌成 data URI）
- **Shift 约束** —— 正方形、正圆、45° 锁角的直线
- **选择 / 移动 / 缩放** —— 8 个手柄，方向键微调（1px，Shift 为 10px）
- **逐元素属性** —— 填充、描边、线宽、不透明度、旋转、水平/垂直翻转
- **图层列表** —— 顶层在前，点击选中，眼睛图标隐藏，上移/下移/置顶/置底
- **撤销 / 重做** —— Ctrl+Z / Ctrl+Shift+Z，最多 60 步
- **缩放视图** —— Ctrl+滚轮或 −/+，缩放视图**不影响**导出尺寸
- **导出** —— 下载 `drawing.svg`，或直接复制源码

## 为什么导出的东西可信

图形以纯数据保存，统一由一个 `el(shape)` 函数渲染成真正的 SVG 元素；导出时**调用的是同一个函数**，
只是不带选中框。所以下载到的就是屏幕上看到的，不是截图，也不是另写一套生成逻辑。

因为是真 SVG（不是 canvas 像素），导出的文件丢进 Figma、Illustrator、Inkscape 或浏览器都能打开，
每个图形仍然可编辑，旋转与翻转通过 `transform` 属性承载。

## 一个值得记下来的 bug

图层标签原来写成按 kind 取值的对象字面量：

```js
// 错的：字面量会先把所有值都求值一遍，矩形上也会执行 s.text.slice()
return { rect: '矩形', text: '文字「' + s.text.slice(0, 8) + '」' }[s.kind] + ' #' + s.id
```

矩形上 `s.text` 是 `undefined`，整个字面量直接抛异常；而这行在检查器渲染路径里，
于是**非文字元素的右侧属性面板会静默不渲染**。改成 `if / else if` 链，只有真的是文字时才碰 `s.text`。

## 快捷键

| 按键 | 作用 |
|---|---|
| `V` `R` `O` `L` `P` `T` | 选择 / 矩形 / 圆形 / 直线 / 画笔 / 文字 |
| 绘制时 `Shift` | 正方形、正圆、45° 直线 |
| 方向键 | 微调 1px（`Shift` 10px） |
| `Delete` / `Backspace` | 删除选中 |
| `Ctrl+Z` / `Ctrl+Shift+Z` | 撤销 / 重做 |
| `Ctrl`+滚轮 | 缩放视图 |

## 怎么用

下载 `index.html` 双击打开。不用安装、不用构建、不用联网。

## 明确不做的事

- 图形只有「轴对齐 + 一个旋转角」，画完之后不能再编辑节点/路径。
- 自由笔存的是原始点列，没有平滑与简化。
- 没有多选、成组、对象间吸附。
- 画布尺寸固定 960 × 600。
